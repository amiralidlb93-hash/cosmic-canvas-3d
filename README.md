# 🌌 Personal 3D Solar System Visualizer | منظومه شمسی شخصی ۳ بعدی

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-GitHub_Pages-38bdf8?style=for-the-badge)](https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/)

An interactive, web-based 3D Solar System Sandbox built with **Three.js**, **Tailwind CSS**, and **Web Audio API**. Customize planets, tweak real-time physical parameters, add personal memory notes, create custom celestial bodies, and fly through space with cinematic auto-tour mode—all localized in both English and Persian (`RTL`/`LTR`).

یک شبیه‌ساز و ویژوالایزر سه بعدی و تعاملی منظومه شمسی توسعه داده‌شده با **Three.js**، **Tailwind CSS** و **Web Audio API**. امکان سفارشی‌سازی سیارات، یادداشت‌نویسی، افزودن اجرام کیهانی جدید و تور سینمایی با پشتیبانی دو زبانه (فارسی و انگلیسی).

## 🚀 Key Features | قابلیت‌های کلیدی

* **🌐 Full Bilingual Support (i18n)**: Instant toggling between **Persian (RTL)** and **English (LTR)** with live localized metrics and descriptions.
* **🎨 Interactive Customization**: Modify planet names, visual color palettes, rotation speeds, and custom personal memory notes.
* **➕ Custom Celestial Creation**: Add brand-new custom planets with dynamic ring systems, custom orbits, and editable properties.
* **🎬 Cinematic Camera Flight**: TWEEN.js-powered smooth transitions, planet focus, and a cinematic **Auto-Tour Mode**.
* **🎵 Cosmic Ambient Audio Engine**: Built-in ambient synth soundscape built with the native Web Audio API.
* **💾 LocalStorage Persistence**: Your custom planets, color changes, and memory notes are preserved in browser storage.
* **📱 Modern Glassmorphism UI**: High-performance responsive interface built with Tailwind CSS and Lucide icons.

## 💻 Tech Stack | تکنولوژی‌های استفاده‌شده

* **Core Engine**: [Three.js](https://threejs.org/) (r128) & OrbitControls
* **Animations**: [TWEEN.js](https://github.com/tweenjs/tween.js/)
* **Styling**: [Tailwind CSS CDN](https://tailwindcss.com/) & Glassmorphism Design
* **Audio Engine**: Web Audio API (Procedural Synthesizer)
* **Icons**: [Lucide Icons](https://lucide.dev/)
